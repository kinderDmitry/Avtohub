# AUTO HUB 4.1.0

Полная production-ориентированная версия AUTO HUB на базе текущего рабочего проекта, расширенная до требований MASTER PROMPT.

## Архитектурный принцип
Local-first: пользовательские данные хранятся локально в SQLite, все основные операции выполняются без обязательного сервера. Записи привязаны к `vehicleId`, поэтому данные автомобилей не смешиваются.

## Функции
- первый запуск: Welcome → автомобиль → Dashboard;
- профиль автомобиля и редактирование;
- обслуживание: история/план, поиск, CRUD;
- топливо: реальные заправки, стоимость, расход по последовательности полных баков;
- расходы и финансовые периоды;
- напоминания по дате/пробегу с Android WorkManager;
- проблемы автомобиля;
- шины;
- документы и сроки;
- запчасти;
- сервисные центры;
- статистика;
- журнал активности;
- JSON и ZIP backup/import;
- единая тёмная neon/glass тема;
- RU/EN;
- уведомления;
- сохранение данных после перезапуска;
- unit tests для математического ядра;
- GitHub Actions для тестов и APK.

## Версия
`4.1.0` / `versionCode 401`

## CI
Workflow: `.github/workflows/build.yml`

Порядок CI: SDK → XML/resource preflight → clean → unit tests → lint → debug APK → проверка APK → artifact.

## Ограничения
Приложение не имитирует OBD, GPS-диагностику, цены, рейтинги СТО или другие внешние данные. При отсутствии пользовательских данных выводится состояние «Недостаточно данных».

## Production UI 4.0.0
Главный визуальный принцип — тёмный автомобильный HUD: глубокий navy/black фон, прозрачные glass-поверхности, cyan neon-контуры, мягкое свечение, единая геометрия карточек и нижней навигации. Графики строятся только по фактическим данным SQLite; при отсутствии данных показывается «Недостаточно данных».
